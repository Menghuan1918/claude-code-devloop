# Git 智能提交

分析当前暂存区的更改，生成并执行一个精简完善的 git commit。

## 功能

1. **智能分析**: 自动分析暂存区的所有更改
2. **信息生成**: 根据更改内容生成规范的提交信息
3. **自动提交**: 执行 git commit 命令
4. **多语言支持**: 支持中英文提交信息

## 分析流程

1. 获取 git status 查看暂存区状态
2. 获取 git diff --staged 分析具体更改内容
3. 获取最近的提交记录了解提交风格
4. 根据更改类型和内容生成合适的提交信息

## 提交信息格式

采用常见的约定式提交格式：
- `feat: 新功能`
- `fix: 修复问题`
- `refactor: 重构代码`
- `docs: 文档更新`
- `style: 代码格式调整`
- `test: 测试相关`
- `chore: 构建/工具链相关`

## 特性

- **智能分类**: 自动识别更改类型
- **内容概要**: 生成简洁的更改描述
- **风格一致**: 保持与项目现有提交风格一致
- **安全检查**: 提交前确认暂存区状态
